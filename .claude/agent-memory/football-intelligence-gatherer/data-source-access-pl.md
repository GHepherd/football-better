WebFetch is blocked (domain verification failure) in this environment for: forebet.com, football365.com, footballwhispers.com, en.wikipedia.org. Do not waste calls trying to fetch them directly.

**How to apply:** Rely on WebSearch with targeted queries instead — its summaries reliably surface odds, predicted lineups, injuries, H2H, and results for Premier League fixtures. Effective query patterns: "<Team A> vs <Team B> <date> prediction preview betting tips", "<Team A> <Team B> head to head last meetings results", "<Team> pre-season <year> results", "<Team> results <month year> Premier League". One well-worded search per data category (odds, lineups, form, H2H) is usually enough for top-flight English football.
