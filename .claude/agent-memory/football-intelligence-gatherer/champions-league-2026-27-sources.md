For 2026/27 Champions League fixtures, these sources surface well in WebSearch summaries (verified during Dortmund vs Villarreal MD1 intel, 2026-09-08):

- **UEFA.com matchday "facts" articles** — official H2H records, team-vs-country historical stats, form streaks. Query the exact article title.
- **BVB.de news/live ticker** — official press-conference injury/suspension updates (Kovac quotes), best for confirmed team news on Dortmund.
- **goal.com betting/tips pages, livescore.com news, bvbbuzz.com** — predicted XIs and injury roundups.
- **sportsmole.co.uk preview + dedicated "injury, suspension list" pages** — most detailed per-club team news (verified for Barcelona vs Feyenoord MD1, 2026-09-09); mundodeportivo.com confirms suspensions in Spanish.
- **foxsports.com game boxscores** — date-stamped final scores for past fixtures (good for building last-10 form lists).
- **en.as.com matchday result pages + footmercato.net live pages** — La Liga/Bundesliga results by matchday with scorers.
- **Odds aggregation via search**: unibet.fr, oddsexplorer.com, footballpredictions.ai, netvasco.com.br summaries return concrete 1X2/O-U/BTTS numbers. Explicit Asian handicap lines rarely quoted — infer AH level from 1X2 pricing (e.g. home ~1.75 => -0.75/-1).
- Wikipedia "YYYY–YY <club> season" pages give season results grids via search summaries.

Verified additions from PSG vs Slovan MD1 intel (2026-09-09):
- **sportsmole.co.uk, whoscored.com previews, khelnow.com** — predicted XIs for big-club matches 24-48h out; PSG.fr notes official lineups only drop 1h before KO, so pre-matchday data is always PREDICTED tier.
- **espn.com/soccer/odds page + robinhood prediction markets** — surfaced full US-odds ladders (1X2, O/U 2.5/3.5, team totals, BTTS) via search summaries; good for exact goal-line reads when AH not quoted.
- **UEFA Europa League history H2H pages** (uefa.com/uefaeuropaleague/history/h2h/) — historical H2H between clubs with match scores.
- espn.com/soccer/team/results pages per club give date-ordered result lists for building last-10 quickly (works for minor leagues too, e.g. Slovak Niké Liga).
