两条校准方法论纪律，均来自 2026-09-11 首次复盘（阿森纳 2-1 切尔西）的自我校正：

**1. 单场优于基线 ≠ 模型有效。** n=1 时，只要实际结果是预测中的热门（如 57.5% 主胜），Brier 与 log loss 必然大幅优于均匀基线——因为基线把 1/3 给了实际未发生的两项。57.5% 的热门命中本就约六成概率发生。因此报告必须做到：基线数字并列（协议硬性要求）**加上**一句明确声明「n=1 时该『优于』几乎不含信息量」。

**Why:** 首次复盘时模型 BS=0.272、log loss=0.553，两项都远好于基线，数字本身很容易被读成模型验证成功。但该场是热门命中，这个结果在模型几乎无效时也会出现。

**2. 「n<5 不得调参」禁令管的是统计推断，不管可复算的算术缺陷。** 若发现的失效是确定性算术错误（一次重算即可判定真伪），它不受样本量禁令约束，可以在 n=1 上建档——因为它不是把噪声抬成规则。

**Why:** 同一场复盘里，推荐注单的失效被定位为一处四分之一球 EV 构造错误（`0.419D − 0.875`，盈亏平衡 D=2.088，市场 2.00 低于平衡点）。这是可复算的事实，与「单场运气」无关。若因 n<5 而不记录，会放任同一个算法缺陷反复发生。

**How to apply:** 写复盘时先问「这个失效是统计性的还是算术性的」。统计性 → 一律标注「样本不足，仅作观察」且不动任何参数；算术性 → 可建档，但仍不得更改任何 λ/参数/概率偏移，只记录正确算式。**How to apply（写作面）：** 每次报告基线对比时，主动写出该结论的信息量上限，不要让读者自己发现。
