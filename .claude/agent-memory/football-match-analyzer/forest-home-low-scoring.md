诺丁汉森林在城市球场的主场比赛呈强烈低比分倾向：截至2026-08，近10个主场9场总进球≤2。

**Why:** 森林主场战术偏保守（三中卫体系），主场对阵利兹联的历史交锋虽由主队连胜但比分多为低净胜。

**How to apply:** 为森林主场比赛建模时，总期望进球 λ_total 应在基准上下调约0.15-0.25；大小球2.5的小球侧与 BTTS No 常出现市场定价偏高（市场易被交锋史60% BTTS误导）。注意与对手近期进攻状态对冲——对手进攻火热时下调幅度减半。相关：[[knockout-totals-bias]]
