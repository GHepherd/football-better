穆里尼奥（2026年7月起二进宫执教皇家马德里）在欧冠大场面（尤其小组赛首轮、淘汰赛）惯用低位防守+反击的保守战术，即使球队拥有强大火力（如姆巴佩、维尼修斯）。

**Why:** 其执教生涯在切尔西、国米、皇马一期、曼联的欧战强强对话中，总进球分布系统性低于两队进攻火力隐含的期望；2026年9月8日皇马vs国米一役，市场大2.5开到1.40（隐含~68%），但模型在计入其战术倾向后（总λ=3.0而非3.5+）给出大球仅57.7%。

**How to apply:** 建模穆里尼奥球队的欧冠强强对话时，总λ在市场隐含基础上下修0.3-0.5；若市场大小球线仍按纯火力定价，小球/BTTS No通常有价值。与 [[knockout-totals-bias]] 可叠加但注意不要双重扣减。
