英超实力接近的对阵（1X2主胜赔2.40-2.70区间），市场归一化概率与Poisson模型通常偏差<3个百分点；即使是显著的单边历史交锋（如布伦特福德对伯恩茅斯近10次不败、客场5连不败），也已被亚盘低水（如客队+0.5压至1.53）充分定价。

**Why:** 2026-09-12 伯恩茅斯vs布伦特福德一役，模型38/26.5/35.5与市场38/27/35几乎重合；此前欧冠做空方向4连击穿的教训表明，"看起来明显的偏差"往往是已定价信息。

**How to apply:** 遇到英超均势对阵时，先跑基础Poisson对比市场归一化；偏差<3个百分点直接报告"无价值、建议观望"，不要用历史交锋单边战绩作为价值论据——此类信息流动性极高，必然已进价格。参见 [[extreme-mismatch-ucl]] 的做空失败教训。
