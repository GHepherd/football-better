亚盘**四分之一球线**（-0.75、+0.75、-0.25、+0.25 等）的期望值与公平赔率，**不能**用「有效胜率 = P(全赢) + 0.5 × P(走盘)，公平赔率 = 1 / 有效胜率」来求。这是错的。

正确的做法是把下注额拆两半，按两个半球线分别结算，再合并：

- **全赢**（弱侧不输 / 让球方赢够）：`+(D − 1)`，概率 `p_w`
- **半输**（对 ±0.75 而言，让球方恰净胜 1 球）：`−0.5`，概率 `p_h` ← **这一档最容易被忽略**
- **全输**（让球方赢够 2 球）：`−1`，概率 `p_l`

`EV = p_w × (D − 1) − 0.5 × p_h − p_l`，整理得 **盈亏平衡赔率 `D* = (p_w + 0.5 × p_h + p_l) / p_w`**。

**Why:** 2026-09-06 阿森纳 2-1 切尔西（英超 R3）实战。模型推荐「切尔西受让半/一（+0.75）」，宣称期望胜率 54–55%（`0.419 + 0.5 × 0.250 = 0.544`）、公平赔率 1.82、市场 2.00 有值。按正确结算，模型自己的分布（全赢 0.419 / 半输 0.250 / 全输 0.331）给出的盈亏平衡是 **D* = 2.088**（水位 1.09），市场 2.00 **低于**平衡点，该注实为 **EV ≈ −3.7%** 的负期望注——宣称的 +5pp 优势方向完全反转。实际赛果恰为阿森纳净胜 1 球，正落在半输档。模型看对了比赛，却把对的判断装进了一个结构上劣于自身判断的注单：同样「1 球定胜负」的判断若落在 +1.0，本场是走盘而非半输。

根因：把四分之一球线当成了「走盘概率可折算为一半胜率」的近似，但 ±0.75 的中间档在真实结算中是**半输**而非走盘（±0.5 与 ±1.0 各半，前者输、后者走）。半球线（±0.5）与整球线（±1.0）不存在此问题。

**How to apply:** 任何以 ±0.25 或 ±0.75（含「半/一」「平/半」等中式叫法）为标的的价值主张，发布前必须按上式复算盈亏平衡赔率，并与市场实际水位比较，不得直接引用 `1 / (p_w + 0.5 × p_h)`。此规则为**确定性算术校验，不依赖样本量**——单场即应执行。相关：[[short-side-fade-caution]]（3pp 门槛是必要非充分条件：门槛通过而模型侧概率算错时，门槛不提供保护）、[[public-sharp-divergence]]。

**⚠️ 半赢档（half-win）是另一套公式，方向不同不可混用：** 上面的 `D* = (p_w + 0.5 p_h + p_l)/p_w` 只适用于**中间档为半输**的线——即受让 +0.75（净负 1 球半输）或让球 -0.25（打平半输）。而**中间档为半赢**的线（受让 +0.25 打平、让球 -0.75 净胜 1 球）结算为 `+0.5(D−1)`，公式完全不同：

`EV = p_w(D−1) + 0.5·p_h(D−1) − p_l = (D−1)(p_w + 0.5 p_h) − p_l`，盈亏平衡 **`D* = 1 + p_l / (p_w + 0.5 p_h)`**。

把半赢档错按半输档（或用 `1/(p_w+0.5p_h)` 近似）会让边际**符号翻转**。2026-09-13 曼联 vs 曼城实战：曼联 +0.25，p(曼联赢)=0.323、p(平)=0.265、p(曼城赢)=0.412 → 半赢档公式 D* = 1 + 0.412/(0.323+0.1325) = **1.905**，市场 1.96 为正价值 +2.9%；若误用半输档公式或 1/0.4555=2.196 会得出错误结论。判据：**结算中间档是「输一半」还是「赢一半」**——前者用 (p_w+0.5p_h+p_l)/p_w，后者用 1+p_l/(p_w+0.5p_h)。

**⚠️ 样本说明：** 本条在 n=1（2026-09-06）上建立，但属可复算的算法缺陷而非统计规律——其正确性由重算确认，不经由样本量确认。本条目**不**授权任何 λ、参数或概率偏移的调整。
