2026-09 布鲁日vs维拉案例：维拉2025年夏窗卖掉整套欧联冠军骨架（Martínez、Watkins、Rogers、Tielemans、Konsa、Digne），新赛季英超3轮0球、4场不胜，但市场仍开出接近平手盘甚至维拉让0/0.5。模型给布鲁日主胜45.5%（公允2.20）vs 市场2.50-2.63，EV +13-19%。

**Why:** 散户记忆锚定上赛季成绩与历史交锋（2025年3月维拉双杀布鲁日），机构不跟随压价，符合 [[public-sharp-divergence]] 模式；历史交锋在阵容完全更替后应降权至约10%。

**How to apply:** 遇到"刚夺冠/高光赛季后夏窗大规模离队+新援磨合期"的球队，先核查其离队核心是否正是此前H2H和成绩的主要贡献者；若是，(1) H2H权重降至≤10%，(2) 向重建队反方向调整1X2概率5-8个百分点，(3) 其让球盘（无论让球方还是受让方对手）通常是价值所在。反向信号优先看新锋线实际进球产出而非纸面身价。
