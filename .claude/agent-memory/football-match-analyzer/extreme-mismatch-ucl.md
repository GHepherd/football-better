在欧冠联赛阶段（如2026-09-09 巴萨vs费耶诺德）这类 1X2 主胜赔率 1.07–1.14 的极端悬殊对阵中，市场对主胜的隐含概率（88-93%）常高于基于双方实际攻防数据的泊松模型结果（约82-85%）。

**Why:** 散户资金重仓豪门 + 博彩公司压低热门赔率防范敞口，导致主胜和大球方向被系统性高估；而模型基于近期实际进失球（费耶诺德跨季19场不败、客场攻击强）给出更接近基本面的概率。

**How to apply:** 遇到主胜赔率低于1.15的对阵，胜平负玩法直接放弃；重点检验客队受让深盘（如+2.5）和大球线（如大3.5）——模型概率若与市场隐含概率偏差超过5个百分点，受让方与小球通常有价值。同时注意豪门防线减员（如De Jong缺阵+中卫停赛）时 BTTS"是"方向往往接近公允，不构成独立价值。相关：[[knockout-totals-bias]]、[[public-sharp-divergence]]

**⚠️ 实战检验记录（2026-09-09，样本n=2，均失败）：** 本条规律建立当日即在两个实例上被证伪——巴萨 5-1 费耶诺德（+2.5受让方向输，巴萨净胜4球）与 PSG 6-1 斯洛万（小3.5/受让+3方向输，PSG净胜5球）。两个案例的共同特征：豪门带着"扭转舆论"动机（PSG14年最差开局后急需大胜、巴萨新援首秀刷信心）且对手实力断层真实存在（费耶诺德19场不败的对手质量远低于巴萨；xG 1.63 vs 0.52 显示巴萨甚至未尽全力）。教训：(1) 模型λ对"真实实力断层"的下修不足——弱队在低级别联赛的不败纪录对顶级豪门几乎无信息量，对手质量加权必须更激进；(2) "轮换/留力"叙事在有强烈舆论反弹动机时权重应下调；(3) 高λ比赛尾部极厚，P(豪门≥5球)≈17%不是小概率尾巴而是常态分布的一部分，受让深盘的EV计算对λ极敏感。本条规律降级为"待验证"，n=2样本不足以下定论，但下一次使用前需重新检验市场偏差是否真实存在而非模型缺陷。
