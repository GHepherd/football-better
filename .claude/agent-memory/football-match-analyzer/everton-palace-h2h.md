埃弗顿自2022年3月后对水晶宫保持不败（截至2026年8月为7胜5平），主场近10次对水晶宫8胜2平；双方近16次交锋13次出现双方进球，水晶宫近10个正式客场无零封。

**Why:** 该对局存在超出纯实力分差的交锋惯性，且双方进球（BTTS是）出现率显著高于联赛平均，市场BTTS赔率通常被压至1.70附近。

**How to apply:** 分析埃弗顿vs水晶宫时，平局与主队不败方向可给予小幅先验加成；BTTS是方向即使模型λ偏低也不宜大幅看空。注意验证该规律是否随教练/阵容更替失效（2026-27赛季水晶宫已换新帅萨热）。
