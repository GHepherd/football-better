football-intelligence-gatherer 在让球盘上反复出现的两类缺口，会直接扭曲亚盘价值判断：

1. **欧洲让球 vs 亚盘口径混标。** Racing Post 类来源的「阿森纳 -1.0 @ 11/8」常是**欧洲 3-way 让球**（净胜2球才赢、净胜1球算"让球平局"=输，**无退款**），而情报会把它注成"净胜1球走盘退款"（亚盘整球语义）。两者结算完全不同：同一场 -1.0，欧洲口径 P=1/0.379≈2.64 无值，亚盘整球口径（走盘退款）公平价≈1.94，若误按亚盘读 2.375 会误判出"巨大价值"。**必须先确认口径再谈水位。**
2. **四分盘形状锁不住。** 前瞻标"亚洲让球 -1.25"却无该口径水位，情报只能并列 -1.0/-1.25/-1.5 而无法判定主盘。四分盘与整球盘在"净胜1球"上从走盘变半输，价值方向可能反转。

**Why:** 2026-09-12 桑德兰 vs 阿森纳（英超）实例：Racing Post -1.0 @ 11/8 被同时标为"欧洲让球口径"与"净胜1球走盘退款"（自相矛盾），Action Network -1.5 @ +132 与桑德兰 +1.5 @ -185 则是标准 2-way。另有 bet365 大小球 Over -138 与其自述"两盘偏小"矛盾（疑 Over/Under 水位写反）。

**How to apply:** 收到让球情报时，(a) 对每个报价先问"这是欧洲3-way还是亚盘2-way"，-1.0 的"走盘退款"只有亚盘成立；(b) 主盘若只给出"净胜≥2才赢"的价位（-1.0 欧洲 / -1.5），用 1/P(净胜≥2) 直接对标，不要套用整球走盘公式；(c) 四分盘/整球盘形状未锁定时，亚盘方向降级或放弃，不替情报选档。相关：[[quarter-ball-handicap-ev-arithmetic]]（半输档必须按 −0.5 结算）、[[extreme-mismatch-ucl]]。
