2026-09-13 曼联vs曼城：曼城联赛近3次做客老特拉福德2负1平（2023年后未联赛客胜）。市场因此只开客让平半浅盘（客胜约2.10-2.20），而非按纯状态差开半球/半一。

**Why:** "魔咒地"叙事广为人知，属于市场完全内化的公开信息；浅盘本身就是定价结果，不是定价错误。Pinnacle 曼城 AH0 @1.67 被部分机构称"价值盘"，但按模型（客胜约45%、主胜约30%）DNB公平赔率恰为约1.68——所谓价值盘实为公平价。

**How to apply:** 建模老特拉福德德比时，主队λ给予常规主场加成即可，不要因"魔咒"叙事额外下修曼城λ或上修曼联胜概率；对"浅盘=价值"的说法保持怀疑，先算DNB/让球公平赔率再判断。相关：[[short-side-fade-caution]]。
