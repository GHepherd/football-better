2026-27赛季初（截至2026-09-09），马竞锋线人手严重不足：索尔洛特肌肉拉伤约4周（本赛季未出场），阿尔瓦雷斯因8月26日病缺训练+转会巴萨风波，联赛未首发、多数媒体预测替补。锋线仅剩卢克曼、戴维/李刚仁可用。4轮联赛已丢6球，刚0-3惨败毕尔巴鄂，近5个客场2胜3负进7丢10。

**Why:** 西蒙尼体系依赖高效反击终结点，两大中锋同时缺阵使客场攻坚能力断崖式下滑；但市场对其"豪门底蕴"定价调整往往滞后。

**How to apply:** 本赛季初分析马竞客场（尤其对强队）时，客场进球λ下修0.2-0.4；同时防线也在丢球，不要盲目买小球，优先在对手让球盘和大球过热时找反向价值。关注阿尔瓦雷斯是否转会成行/恢复首发——若解决则需重新校准。与 [[ucl-giant-deep-handicap-rotation]] 联动：马竞自己也可能成为被深盘定价但阵容不整的一方。
