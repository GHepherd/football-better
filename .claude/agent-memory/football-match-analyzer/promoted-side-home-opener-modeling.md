英超/英冠升班马主场赛季揭幕战（如2026-08-22赫尔城vs曼联）的建模规律：

**Why:** 此类场次市场通常把强队客胜压到~70%但亚盘只开-1.5且强队赔松动；升班马主场情绪溢价真实存在，但主要集中在开场阶段（上半场平局率历史偏高）；同时升班马常伴随伤病潮/阵容不整，两股力量对冲后，强队赢2球以上的概率往往不足五成。

**How to apply:**
- 用泊松模型将客胜概率校准到市场公允值（去掉水位），反推λ差，而不是凭实力差直接给λ
- 重点检查 -1.5 盘口：强队赢盘概率 <50% 时，弱队+1.5 是唯一可能有边际价值的方向，但优势通常极薄（<1个百分点），只配小注
- 正确比分分布呈双峰（强队2-0零封 vs 2-1/3-1对攻），单一最高概率比分（如0-2）可能恰好落在大小球线另一侧——此时大小球不宜重注，警惕"资金大球 vs 专家零封"的信号矛盾
- 若有滚球/半场市场，"半场平"比全场市场更适合捕捉揭幕战情绪溢价
