欧冠联赛阶段（新赛制）豪门主场对资格赛晋级弱旅时，市场深盘（-2.5/-3）和大球线（3.5）隐含的是"全主力+全力争净胜球"情景。当存在以下任一信号时，应系统性下修主队进球λ（约0.4-0.7）：(a) 3-5天后有联赛重头戏（如国家德比）；(b) 锋线核心首发存疑/轮换；(c) 对手资格赛靠摆大巴晋级且联赛显露疲态（更倾向死守保尊严）。

**Why:** 2026-09-09 PSG vs 斯洛万案例：市场大3.5 @1.68（隐含~55%），但登贝莱存疑+9月20日国家德比留力+图雷五后卫死守，模型λ_total仅3.45，小3.5实际概率~55%（公平1.81），小3.5 @2.03有约+12% EV。PSG -3 @2.01隐含覆盖~50%，模型覆盖仅~28%，深盘严重高估。

**How to apply:** 联赛阶段首轮/中段豪门深盘，先查7天内赛程与首发轮换信号；若存在，总λ下修后对比大小球主盘，小3.5和客队受让(+3)常同时出现价值。与 [[public-sharp-divergence]] 联动：散户重仓豪门大胜叙事时偏差更大。
