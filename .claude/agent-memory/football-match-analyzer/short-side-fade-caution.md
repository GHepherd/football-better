2026-09-11 team-lead 提示：前两轮欧冠复盘中，做空方向（fade 热门/小球的反向判断）已连续4次被击穿。

**Why:** 近期多次将"市场高估热门"判断为价值，结果市场定价才是对的；样本指向模型对强势方调整不足，或把噪音当成了偏差。

**How to apply:** 当模型概率与市场隐含概率差距 ≤3pp 时，不得报告为"价值"，直接输出"市场高效、无价值、建议观望"。只有当差距 >3pp 且有明确情报支撑（伤停、轮换、天气等市场未定价的硬信息）时才可主张偏差，并须注明敏感度。与 [[extreme-mismatch-ucl]] 的失败教训一致。
