2026-08-22 布伦特福德vs热刺案例：78–83%散户注单压热刺客胜，但客胜赔率不降反升（+170→+180），机构未跟随。模型判断散户方向错误，赛后可验证。

**Why:** 传统豪门（热刺、曼联等）存在系统性品牌溢价，散户注单集中时机构若不接受该价格（不降赔），说明机构风险评估站在散户对立面，这是比赔率本身更强的信号。

**How to apply:** 收到情报含"散户注单比例 vs 赔率动向"数据时，若出现背离（散户重仓某方而该方赔率漂移走弱），将该方概率相对市场隐含值下调3–7个百分点，并在价值判断中标注"散户/机构背离"。与 [[knockout-totals-bias]] 一样属于市场微观结构修正项。
