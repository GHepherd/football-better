  type: feedback

2026-09-08 欧冠方案复盘发现的映射错误：方案把"皇马(-1)让负"标注为等价于 analyzer 推荐的"国米+0.5/国米不败"。实际竞彩让球胜平负规则下，主队让1球、主队2-1取胜时，调整后为1-1，结算为**让平**，让负注不中奖——该场皇马恰以2-1获胜，此注因此失效。

**Why:** analyzer 的亚盘/欧赔让球概念（+0.5 即不败即赢盘）与竞彩固定整数让球的胜平负结算不同：让N球时，"让胜/让平/让负"分别对应主队净胜>N、=N、<N。"受让方不败"对应的是让0盘的让负或让1盘让负+让平的部分组合，不能简单画等号。

**How to apply:** 把 analyzer 的让球方向翻译成竞彩选项时，必须按具体让球数逐盘推演三种赛果的归属：
- "受让方不败"（如+0.5赢盘）→ 让1球时应拆为 让平+让负 双选，或改用胜平负双选/让0盘
- "受让方+1.5"→ 对应让1球的 让平+让负
- 主队让1球时，主队恰好净胜1球是最常见的落点之一（约20-25%），映射时绝不能让这一落点漏出覆盖范围
- 补充（2026-09-11 阿森纳vs切尔西复盘前）：analyzer 报「受让方 +0.75」价值时，竞彩同样无此档位。+0.75 = +0.5（平/客胜即赢）+ +1.0（主队净胜1球走盘）两半；竞彩要近似保真需「让平 + 让负」双选各半注，单买「让负」会漏掉主队净胜1球（约25%）的让平落点。且这两档竞彩赔率普遍偏短，双选组合后 EV 仍常为负——亚盘下盘价值在竞彩整数让球下无法保真，可直接判观望。
