竞彩足球没有大小球和双重机会玩法，analyzer 的市场结论需做如下转换：

- **小2.5球**：竞彩只能用「总进球」买 0/1/2 球三个互斥选项组合，有效赔率 = 1/(1/o0+1/o1+1/o2)，通常远低于欧赔小2.5（例如欧赔2.88 折算后常只有1.5-1.9）， analyzer 报的大小球价值缺口在竞彩端可能完全消失。不要直接把欧赔大小球价值当成竞彩总进球价值。
- **客队+0.5（受让方不败）**：等价于「让球胜平负」主队让1球时的「负」选项（主队-1后不胜 = 平局或客胜）。皇马让1球「让负」≈ 国米+0.5。
- **主队不败（双重机会1X）**：等价于主队受让1球(+1)时的「让球胜」。
- **竞彩赔率普遍低于欧赔10-20%**（返奖率约70%）：analyzer 给的「最低可接受赔率」若按欧赔计算，竞彩端需重新核对，临界价值的腿在竞彩端经常不达标。
- 欧冠焦点战通常开售「胜平负单关」和「让球胜平负单关」，但以实际开售公告为准，方案中须给出无单关时的备选。
- 比分玩法竞彩水位抽成最重，即使 analyzer 概率第一的比分（如11-12%的1-1），EV 也常为负，只适合做≤2元的博冷注，不做主力。
