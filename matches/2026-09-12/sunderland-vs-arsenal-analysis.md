## 亚盘分析（主盘形状存疑 — 本场关键）

先给出由进球差分导出的**四档基础概率**（阿森纳视角的净胜差）：

| 情景 | 概率 |
|---|---|
| 阿森纳净胜 ≥2 球 | **37.9%** |
| 阿森纳净胜 1 球 | **26.4%** |
| 平局 | **22.2%** |
| 桑德兰 胜 | **13.5%** |

据此，三个候选主盘 + 一个相邻盘如下（公平赔率为**盈亏平衡价**，即 EV=0 的水位）：

### 候选 A — 阿森纳 -1.0（整球盘）
| 结算 | 概率 |
|---|---|
| 净胜≥2：全赢 | 37.9% |
| 净胜1：**走盘退款** | 26.4% |
| 平/负：全输 | 35.7% |

- 公平赔率：阿森纳 -1.0 = (0.379+0.357)/0.379 = **1.94**；桑德兰 +1.0 = (0.357+0.379)/0.357 = **2.06**。
- 去走盘后两方向盖率：阿森纳 51.5% / 桑德兰 48.5%，**最接近五五开的公平线即 -1.0**。

### 候选 B — 阿森纳 -1.25（四分盘，最可能但未锁定的主盘）
下注额拆两半：半仓 -1.0、半仓 -1.5。
| 结算 | 概率 | 明细 |
|---|---|---|
| 净胜≥2：全赢 | 37.9% | -1.0 半赢 + -1.5 半赢 |
| 净胜1：**半输** | 26.4% | -1.0 半仓走盘、-1.5 半仓输 → −0.5 |
| 平/负：全输 | 35.7% | 两仓皆输 |

- 公平赔率：阿森纳 -1.25 = (0.379 + 0.5×0.264 + 0.357)/0.379 = **2.29**（半输档按 −0.5 结算）。
- 桑德兰 +1.25（镜像：净胜1时**半赢**）= (0.357 − 0.5×0.264 + 0.379)/0.357 = **1.69**。
- **-1.0 与 -1.25 的唯一差别就在"净胜1球"：前者退款、后者半输。** 情报若无法锁定是哪一档，任何让球价值结论都悬空。

### 候选 C — 阿森纳 -1.5（半球盘，Action Network 已报价）
| 结算 | 概率 |
|---|---|
| 净胜≥2：赢 | 37.9% |
| 否则：输 | 62.1% |

- 公平赔率：阿森纳 -1.5 = 1/0.379 = **2.64**；桑德兰 +1.5 = 1/0.621 = **1.61**。
- 市场（Action Network）去水后约 阿森纳 -1.5 **40%** / 桑德兰 +1.5 **60%**；模型 37.9% / 62.1%。→ 市场略比模型更看好阿森纳净胜2球，偏差约 2–3pp，**不足以成边**，且两侧水位均低于公允（正常抽水）。

### 相邻盘 — 阿森纳 -0.75（四分盘）
下注额拆两半：半仓 -0.5、半仓 -1.0。
| 结算 | 概率 | 明细 |
|---|---|---|
| 净胜≥2：全赢 | 37.9% | 两仓皆赢 |
| 净胜1：半赢 | 26.4% | -0.5 赢、-1.0 走盘 → +0.5 |
| 平：半输 | 22.2% | -0.5 输、-1.0 走盘 → −0.5 |
| 负：全输 | 13.5% | 两仓皆输 |

- 公平赔率：阿森纳 -0.75 = (0.379 − 0.5×0.264 + 0.5×0.222 + 0.135)/0.379 = **1.30**；桑德兰 +0.75 = (0.135 − 0.5×0.222 + 0.5×0.264 + 0.379)/0.135 = **3.96**。

### 亚盘小结
- **公平主盘在 -1.0 附近**（去走盘后阿森纳侧约 51.5%）；市场报出的 -1.25/-1.5 暗示市场对"阿森纳净胜2球"的定价（约 40–43%）**高于**本模型的 37.9%。
- 结论：模型在让球方向**略偏桑德兰受让侧**（+1.5 模型 62.1% vs 市场 60%），但偏差 2–3pp 且水位已扣除，**不构成可下注边**。真正的风险是**盘口形状未锁定**——在 -1.0 与 -1.25 之间，同一场比赛的让球注会从"走盘"变成"半输"，价值方向可能反转。

## 关键洞察与警示

1. **阿森纳"低比分小胜"是本场全部市场的主轴**：本季 5 战全胜仅失1球、4场零封，但客场比分偏小（1-0 维拉、1-0 那不勒斯）；桑德兰联赛场均进1球且主场防守扎实。两者叠加 → 0-1 / 0-2 / 0-0 合计约 37%，"小球 + 阿森纳净胜1球"是最高密度区间。
2. **让球盘形状是本场最大不确定性**，直接决定 -1.0/-1.25 从"走盘"变"半输"。若赛前无法以单一亚盘源复核，亚盘方向应降级处理或放弃。
3. **模型敏感性：** 若把阿森纳客场 λ 从 1.80 上调到 1.95（反映其进攻质量 + 桑德兰两主力攻击手缺阵），阿森纳净胜≥2 概率将从 37.9% 升到约 42%，届时 -1.25/-1.5 的"阿森纳侧"与小球方向都会削弱；反之若下调到 1.65（重视桑德兰主场韧性与上季 2-2 交锋），小球与桑德兰受让边会增强。**当前取值处于两端之间，任何让球/大小球结论对本假设敏感。**
4. 桑德兰 4 天后有欧联首战（AZ Alkmaar），或影响下半场逼抢强度与换人，对"阿森纳净胜2球"是潜在下修因素。

## 推荐投注

**结论：无强边，市场整体高效。** 本场为英超高关注度强弱对阵，1X2 与 -1.5 让球均已充分定价（偏差 ≤3pp）。

唯一可列为**弱价值**的方向：

- **市场：总进球 小球 2.5（Under 2.5）**
- **概率：54.9%**（隐含 1.82）
- **最低可接受赔率：2.05**（约 7% 边；低于此不值得承担"bet365 报价矛盾 + 让球形状未锁定"的噪声）
- **信心：低**
- **理由：** 三条独立信号（Action Network 52.8% 去水、Goalence 60%、OneFootball 4/5）与模型同向偏小，主旋律"阿森纳低比分小胜"支持。但大小球市场存在 bet365 疑似转录矛盾，且小球方向与"阿森纳净胜2球"此消彼长，故只作弱价值、严格限赔。

**放弃方向：** 亚盘让球（盘口形状未锁定，任何单一让球线结论悬空）；1X2（高效无值）；正确比分无单一可下注对象（0-1 无市场水位可比）。
